MeshCore OTA Push

Build a signed update in this browser and push it to one or more specific nodes through a repeater on USB. Nothing is uploaded anywhere: the firmware and your signing key stay on this computer.

1 Package

An OTA build (ENABLE_OTA, carries the EndF trailer): ESP32 firmware.bin, nRF52 firmware.hex, or a ready .mota.

Must be the exact image running on the node. Leave empty to send the full image. Automatic delta type: .hex = nRF52 in-place, .bin = ESP32 sequential.

Load key file · Create a new key

2 Repeater on USB

Any of your nodes running OTA firmware with ota folder support. It serves the package to the mesh and sends the nudges.

3 Nodes to update

The full key or at least its first 12 hex chars. Each node acts only if it has run, once: ota key add <your signing public key> and ota config push trusted.

Retry settings

Send update request: this page sends the requests and serves the update, so keep it open until the nodes have it. Hand over to the USB node: the USB node copies the update into its own memory, serves it and sends the requests itself, so you can disconnect the computer. That node must trust your signing key too (ota key add) and keeps one update at a time.
